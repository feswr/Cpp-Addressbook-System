# C++ 通讯录管理系统 (C++ Address Book System)

这是一个由我在学习过程中独立编写的 C++ 通讯录管理系统。旨在通过实践巩固 结构体，指针，基础语法操作等核心知识点，并通过网络渠道学习到了I/O文件知识
项目功能
1.添加联系人：支持输入姓名、年龄、性别、电话和家庭住址。
2.显示联系人：以列表形式展示所有联系人信息。
3.查找联系人：根据姓名查找并显示指定联系人。
4.修改联系人：根据姓名定位并修改需要更改的联系人信息
5.删除联系人：根据姓名定位并删除，并自动将后续数据前移补齐。
6.清空通讯录：自行添加了二次确认的清空功能。
7.数据持久化：多次运行程序后不会因为关闭程序而丢失数据。

用到的核心技术 
1.语言：C++
2.指针与内存：运用了学习到的指针来传递结构体数组，防止在规模较大时形参拷贝量过大。
3.文件 I/O：最后学会了使用 `ofstream` 和 `ifstream` 进行文本文件的按行读写操作，增强了一些实用性
