# C++ 通讯录管理系统 (C++ Address Book System)

这是一个由我在学习过程中独立编写的 C++ 通讯录管理系统。本项目旨在通过实践，巩固 结构体、指针操作等核心知识点，并通过网络渠道学习到了I/O文件知识
项目功能
1.添加联系人：支持输入姓名、年龄、性别、电话和家庭住址。
2.显示联系人：以列表形式展示所有联系人信息。
3.查找联系人：根据姓名查找并显示指定联系人。
4.修改联系人：根据姓名定位并修改需要更改的联系人信息
5.删除联系人：根据姓名定位并删除，并自动将后续数据前移补齐。
6.清空通讯录：自行添加了二次确认的清空功能。
7.数据持久化：使用 `<fstream>` 实现数据的本地文件保存与读取。程序退出时自动保存至 `AddressBook.txt`，启动时自动加载，退出程序后数据不丢失。

用到的核心技术 
1.语言：C++
2.指针与内存：全程使用指针传递 `AddressBook*`，避免大结构体拷贝，提高效率。
3.文件 I/O：使用 `ofstream` 和 `ifstream` 进行文本文件的按行读写操作。
